# Crystal-Renderer
A renderer in **vulkan** in C++. Pretty cool.

Features ->
- Lighting
- Model loading
- Complete scene loading
- PBR
- Audio support
- Shader support

> Still in development. Code may not be that good 😅

### When compiling 

Libraries needed ->
- SDL3
- ImGui
- Stb
- glm

Put them in a folder named "libs" and compile the project.
